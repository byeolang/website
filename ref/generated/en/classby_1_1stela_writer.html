Detailed Description

Serializes a stela tree back to stela source text.

Implemented as a stelaVisitor. writes a canonical, lossy form. What is NOT preserved:

  • comments in the original file
  • original whitespace, blank lines, and indentation width beyond the writer's configured indent
  • the original insertion order of children (std::map inside Stela sorts them alphabetically)
  • the exact literal spelling of numbers (e.g. 1_000 becomes 1000)

What IS preserved: values and structure. Round-trip parse -> edit -> write -> parse gives the same value tree, and write -> parse -> write produces the same string (canonical fixed point).

Root handling

The writer serializes a compilation unit, so it accepts only a rootStela: handing write() or writeFile() any other node is rejected (empty string / false). The rootStela itself is never emitted as def <name> — only its children are — matching the shape of stela source, where the top level is implicit.

Usage

std::string src = stelaWriter().write(*root);
stelaWriter().writeFile(*root, "out.by");
