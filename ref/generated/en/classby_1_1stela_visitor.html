Detailed Description

Preorder visitor for the stela AST.

Mirrors byeol's visitor in miniature. Each visit goes through three phases:

  1. onVisit() — inspect the node; return false to skip the subtree.
  2. onTraverse() — descend into children (default: iterate the child map).
  3. onLeave() — post-visit hook.

Typed overloads (onVisit(..., valStela&)) are dispatched from each subclass's accept() (injected by the VISIT macro). A type-specific override that is not provided chains up to onVisit(..., stela&) via the super typedef, matching byeol's convention.

stela trees are pure (no shared subgraphs), so unlike byeol's visitor no visited-set is maintained.
