Detailed Description

Named block of children — the def form of stela source.

A tag subtype so stelaWriter emits a def <name> block. It adds no storage and no methods: children are ordinary Stela children, so every access goes through the plain Stela interface.

This is what Stela itself used to be. Stela is abstract now, and the def-block behaviour that only a block should have lives here, so a sibling form like arrStela no longer inherits it.

Usage

defStela root("root");
root.add(new strStela("byeol", "name"));
