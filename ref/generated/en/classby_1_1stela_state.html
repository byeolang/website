Detailed Description

The state a construct carries across the gap between the scanner and bison's reductions.

The scanner runs ahead of the reductions, so when a comment is scanned the node it belongs to does not exist yet. That pending state lives here as one comment stack plus a cursor, instead of a flag per construct spread across stelaParser:

  • location tracks where the scanner sits on the line, so a comment routes to a prefix or a postfix.
  • the stack mirrors nesting: entering a def or an assignment pushes a frame, reducing it pops the frame onto the node – both the same way.
